# AutoFlow — V11 Logo + Banner

Atualização visual sobre a V10.

## Alterações desta versão
- Logo oficial do AutoFlow substituída pela arte enviada pelo usuário.
- Logo preparada em PNG com fundo transparente para uso no cabeçalho, rodapé e telas do protótipo.
- Novo espaço de banner promocional na página de busca, imediatamente acima de “Empresas em destaque”.
- Banner promocional recebido pelo usuário incorporado como `assets/banner-promocao.jpg`.
- Banner responsivo, mantendo a proporção da arte e sem sobreposição de textos do sistema.
- Mantida a estrutura anterior de empresas em destaque, status online e demais telas.

## Arquivos principais
- `index.html` — página inicial
- `busca.html` — marketplace + banner promocional + empresas em destaque
- `cadastro.html` — cadastro e planos
- `detalhe.html` — página da empresa
- `agendamento.html` — agendamento
- `assets/autoflow-logo.png` — nova logo
- `assets/banner-promocao.jpg` — banner promocional
- `assets/style.css` — estilos
